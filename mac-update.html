PollSlide Companion for Mac

Update PollSlide Companion

It takes about two minutes. You stay connected to your account — no new code needed.

Which version do I have?

Click the bar-chart icon in the menu bar at the top right of your screen, then “About PollSlide Companion”. From version 1.3.5 the version number is shown there. If you see no number, you have version 1.3.4 or older — please update.

Update in six steps

  1. Quit the old app. Click the bar-chart icon in the menu bar, then “Quit”.
  2. Remove the old version. In Finder, open Applications and drag PollSlide Companion to the Trash. If you have another copy in Downloads or on a disk image, remove that too — two copies confuse macOS permissions.
  3. Download the new version. Get it from pollslide.com/download.
  4. Install it. Open the downloaded .dmg file and drag PollSlide Companion into your Applications folder. Then eject the disk image.
  5. Open it from Applications. You stay connected to your PollSlide account — you don't need a new code.
  6. Check Screen Recording. Open System Settings → Privacy & Security → Screen Recording (on newer macOS: Screen & System Audio Recording) and make sure PollSlide Companion is switched on. Then quit the app and open it again.
Slides not detected after updating? macOS sometimes keeps the old app's permission. In Screen Recording, switch PollSlide Companion off and on again, then quit and reopen the app. If it is listed twice, remove both entries with the minus button, open the app again and allow it once.

Check it worked

Open “About PollSlide Companion” again — it now shows the new version number. Present a slide with a PollSlide QR code and the results window appears as usual.
